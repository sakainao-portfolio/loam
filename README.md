# ☕ コーヒーロースターカフェ 架空サイト

学習の一環として制作した、コーヒーにこだわる大人がターゲットのロースターカフェの架空Webサイトです。

## 🔗 デモサイト
- 公開URL： https://sakainao-portfolio.github.io/loam/

## 🛠️ 使用技術
- HTML5 / CSS3

## 💡 工夫したポイント・設計
- **トンマナと配色:** 高級感と温かみを感じさせるため、柔らかな漆喰調ホワイト（`#E6E4E0`）、深いダークブラウン（`#2B2721`）、スモーキーなティール（`#446E72`）を基調にデザインしました。
- **コード設計:** `outer` → `wrapper` → `article` の階層ルールを意識し、保守性の高いHTML/CSS構造を心がけました。
- **レイアウト:** ゆったりとした空気感や落ち着きを表現するため、余白やゆとりのある配置を目指しました。
- **ビジュアル・質感のこだわり:** トーンを統一したシズル感のある画像を使用し、温かみや品質のこだわりを表現しました。
